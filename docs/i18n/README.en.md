<h2 id="readme-about">🌟 About the SparkAi Commercial System</h2>

**SparkAi is a { Progressive } AIGC system with multi-language internationalization support – a one-stop AI system built on OpenAI/ChatGPT, the latest flagship model GPT-6, Anthropic Claude (Claude-Opus-5-5 / Claude-Fable-5-1), Google Gemini, DeepSeek, 🎨GPT-Image-2 / GPT-Image-2.5 painting, 🍌Nano-Banana-2 second-generation painting, Midjourney V8, VEO3.1 / Sora-2 video, Seedance2.5 video (coming soon), Agent intelligent agents with Coze plugins, workflows, functions, knowledge bases, and other large-model capabilities; it supports "🤖AI Chat", "🎨Professional AI Painting", "🧠AI Agents", "🪟Coze-Agent Workflow Apps", "🎬AI Video Generation", etc., and supports independent private deployment!**

It provides comprehensive solutions for individual users (ToC), developers (ToD), and enterprises (ToB).

🏅 **As of September 2026, SparkAi has been under continuous development and iteration for three and a half years**, with a steady cadence of major releases. Recent major versions focus on:

- 🧩 **Full model support / custom integration of the latest models**: OpenAI, Claude, Gemini, mainstream domestic models, and third-party models all use the standard chat format, so newly released models can be added freely in the admin backend without a system update
- 🎨 **Multi-function / multi-type model painting**: text-to-image, reference-image generation, online image editing, partial brush-edit repainting, and image-to-text (multimodal image understanding), covering GPT-Image-2 / GPT-Image-2.5, Nano Banana 2, Midjourney V7 / V8 and more
- 🤖 **New-generation dialogue architecture**: automatic routing between Chat Completions / Responses endpoints; switching sessions or closing the page does not interrupt generation
- 📄 **Multi-type document understanding**: upload recognition and online preview of PDF / Word / PPT / Excel and other files
- 💰 **Points and account security**: points details reconciliation, zero charge on failed model calls, login device and remote-login detection

See <a href="https://docs.sparkaigc.com/en/docs/guide/" target="_blank" rel="noopener noreferrer">System Core Functions</a> and the <a href="https://docs.sparkaigc.com/en/log/" target="_blank" rel="noopener noreferrer">Changelog</a> for more details.

<h2 id="readme-deploy">🛠️ Installation and Deployment</h2>

### Option 1: Baota Panel - Official Docker Store One-Click Deployment (Recommended)

- See the **<a href="https://docs.sparkaigc.com/en/deploy/baota/process.html" target="_blank" rel="noopener noreferrer">detailed installation and deployment tutorial</a>**
- Install Baota Panel (version 9.2.0 or above) using the stable script from the <a href="https://www.bt.cn/new/download.html" target="_blank" rel="noopener noreferrer">Baota website</a>
- Log in to Baota Panel and click Docker in the menu; on first visit you will be prompted to install the Docker service. Click "Install Now" and follow the prompts
- Search for **SparkAi** in the app store, find SparkAI-ChatGPT-AiWeb, click install, and configure the basic options to finish

### Option 2: Node.js + PM2 Deployment

> You can also refer to the <a href="https://docs.sparkaigc.com/en/deploy/baota/process.html" target="_blank" rel="noopener noreferrer">official installation tutorial of the licensed version</a>

**1. Prepare the environment**

- Use <a href="https://github.com/nvm-sh/nvm" target="_blank" rel="noopener noreferrer">nvm</a> to install Node.js 16.0 or later:

  ```bash
  nvm install 16
  nvm use 16
  node -v
  ```

- Install PM2 and pnpm, and check that they run:

  ```bash
  npm install pm2 -g
  npm install -g pnpm
  pm2 -v
  pnpm -v
  ```

**2. Configure the project**

- Copy `.env.example` to `.env` and adjust the settings as needed
- Run `pnpm i` to install dependencies (switch to a mirror registry if installation is slow)

**3. Start the project**

- Run `pnpm start`; the service listens on port 9520 by default
- Open `http://localhost:9520` in your browser, or your domain if you configured an Nginx reverse proxy

**4. Upgrade**

```bash
git pull        # pull the new bundle
pm2 del all     # remove old PM2 processes
pnpm i          # install dependencies
pnpm start      # start the service (port 9520 by default)
```
